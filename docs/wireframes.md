# Схемы экранов

Актуальная версия соответствует дизайну по образцам Яндекс Трекера. Данные в схемах обозначают типы содержимого, а не записи для интерфейса.

## Общая оболочка

```text
┌────┬─────────────────────────────────────────────────────────┐
│ ☰  │ Главная / Текущая страница       Поиск задач    Аккаунт │
│ +  ├─────────────────────────────────────────────────────────┤
│Дом │ Заголовок                             Основное действие │
│Зад │ Вкладка 1   Вкладка 2   Вкладка 3                       │
│Пр. │ ─────────────────────────────────────────────────────── │
│Дос │ Фильтры / поиск                                         │
│Сот │                                                         │
│Заг │ Рабочая область                                         │
│Наст│                                                         │
└────┴─────────────────────────────────────────────────────────┘
```

Меню 64 px раскрывается до 232 px. На телефоне открывается поверх содержимого.

## Моя страница

```text
Моя страница                          [Назначены мне]
Обзор предприятия | Все задачи
Задач      Просрочено      Проектов      Сотрудников
─────────────────────────────────────────────────────
┌ Ближайшие сроки ─────────────────┐ ┌ Проекты ───────┐
│ Ключ, название, статус, дедлайн  │ │ Название, код │
│ ...                             │ │ ...           │
└─────────────────────────────────┘ └───────────────┘
┌ Загрузка подразделений ──────────┐ ┌ Загрузка ──────┐
│ Период, линии, проценты         │ │ Средняя, выше │
└─────────────────────────────────┘ └───────────────┘
```

## Сотрудники

```text
Сотрудники                              [+ Сотрудник]
Команда | Загруженность
[Подразделение] [Загрузка] [Сортировка] [Применить]
[Поиск по имени, email, должности]
Сотрудник / email | Должность | Отдел | Загрузка | Статус
... строки реальных сотрудников ...
```

Карточка сотрудника: имя и аватар → вкладки Обзор / Задачи / График / Отсутствия. Обзор содержит контакты и условия работы слева, загрузку справа.

## Проекты и задача

```text
Название проекта / задачи
Вкладки проекта или меню статуса задачи
┌ Основное содержимое ────────────┐ ┌ Параметры ─────┐
│ Описание                       │ │ Статус        │
│ Задачи / планирование          │ │ Ответственный │
│ Команда проекта                │ │ Даты          │
└────────────────────────────────┘ │ Приоритет     │
                                   └───────────────┘
```

Проекты представлены таблицей. Список задач поддерживает серверные фильтры. Ссылки открывают реальные карточки.

## Доска

```text
Название проекта                         [+ Задача]
О проекте | Список | Доска
[Проект] [Поиск по доске] [Приоритет] [Просроченные]
┌ Запланировано ┐┌ В работе ──┐┌ Проверка ─┐┌ Выполнено ┐
│ [Испол. Ключ] ││            ││           ││           │
│ [Название   ] ││            ││           ││           │
│ [Статус Срок] ││            ││           ││           │
│ [Часы / Load] ││            ││           ││           │
└───────────────┘└────────────┘└───────────┘└───────────┘
```

## Создание задачи

```text
Доска за затемнением      ┌ Новая задача ─────────── [×]┐
                         │ Основное                    │
                         │ Название, описание, проект  │
                         │ Планирование                │
                         │ Даты, часы, приоритет       │
                         │ Исполнитель [Рассчитать]    │
                         │ Кандидаты: сейчас → после   │
                         │ При CRITICAL: причина, ✓    │
                         ├─────────────────────────────┤
                         │ [Отмена] [Создать задачу]   │
                         └─────────────────────────────┘
```

Прокручивается только тело формы. Footer находится в отдельной области и не перекрывает поля.

## Загруженность

```text
Загруженность
По сотрудникам | Команда
[Подразделение] [Начало] [Окончание] [Показать]
Легенда статусов
Сотрудник | За период | Статус | Дневные ячейки →
... реальная дневная загрузка ...
                           Нажатие → панель дня
```

Панель дня содержит ФИО, дату, доступные и назначенные часы, процент, статус и переход к сотруднику.

```text
... записи выбранного справочника ...
```
