# Проверка редизайна

## Автоматические проверки

Команда из корня: `mvn -B -ntp test`.

- Существующий тест сервиса расчёта нагрузки.
- Рендеринг новых карточек сотрудника и проекта, в том числе при недоступном сервисе загрузки.
- Рендеринг всех административных разделов при пустых данных.
- Запрет доступа обычного сотрудника к администрированию и UI Kit.
- Ответ 404 для отсутствующих сотрудников и проектов.
- Рендеринг UI Kit при профиле dev и роли ADMIN.
- Регрессия dashboard с нагрузкой 134%.
- Регрессия формы проекта: значения priority и ISO-даты.

## Проверки в браузере

Браузер Playwright подключён к реальному приложению на localhost:8080. Авторизация через демо-аккаунт admin. Данные базы не пересоздавались.

Проверены HTTP 200 и отсутствие необработанных `th:field` / `th:text` на 16 адресах: dashboard, employees, employees/new, projects, projects/new, kanban, workload, employees/1, projects/1 и семь разделов admin.

На ширинах 1440 и 390 px проверены основные списки, Kanban, workload и admin: нет горизонтального переполнения всей страницы, поля имеют labels или aria-label. Сохранены скриншоты в `output/playwright/`.

В реальном запросе workload-preview получены три кандидата. Проверены выбор кандидата, сброс выбора при изменении часов, появление CRITICAL и отсутствие автоматического подтверждения перегрузки. Создание тестовых сотрудников, проектов и задач в базе не выполнялось.

## Обнаруженные и исправленные ошибки

1. Неоднозначная перегрузка Math.min в SpringEL графика: ограничение ширины перенесено в CSS min, полный процент сохранён в тексте.
2. Отсутствующие value в option формы проекта: добавлены явные значения.
3. Локализованные даты в input type=date: DTO помечены DateTimeFormat ISO.DATE.
4. Передача CSRF: token/header берутся из Thymeleaf meta; cookie оставлена как fallback.
5. Устаревший результат асинхронного расчёта: счётчик поколения игнорирует ответ после изменения параметров.
6. Drag-and-drop: ссылка на карточку сохраняется до await, чтобы dragend не обнулял объект во время PATCH.

## Что не подтверждено этой проверкой

Окончательная сборка после исправления ISO-дат успешно прошла Maven: 8 тестов страниц и 1 тест нагрузки. Docker пересобрал и запустил enterprise-app. До финальной пересборки Playwright подтвердил desktop/mobile layout, все основные маршруты, расчёт кандидатов, сброс выбранного кандидата после изменения часов и обязательное подтверждение CRITICAL. Последние изменения затрагивают форматирование дат, порядок слоёв и документацию; их серверный рендеринг покрыт тестами.

Полный цикл записи сотрудника, проекта и задачи в рабочей демонстрационной базе не выполнялся, чтобы не изменять демонстрационные данные при проверке. Проверки accessibility не являются полным аудитом WCAG или проверкой экранным диктором. Реальная работа CDN по-прежнему требуется, как и до редизайна.
