## Роли и область данных

- [x] ADMIN управляет справочниками, пользователями, сотрудниками и ML-моделью.
- [x] ENTERPRISE_MANAGER видит аналитику всей организации, но не получает административные формы.
- [x] DEPARTMENT_MANAGER видит индивидуальные прогнозы только своего подразделения.
- [x] PROJECT_MANAGER не получает доступ к индивидуальным прогнозам текучести и отчётам по ним.
- [x] EMPLOYEE не получает доступ к кадровым прогнозам других сотрудников.
- [x] Изменение пользователя, сотрудника, отсутствия, навыка, проекта, задачи и ML-модели записывается в аудит.

## Интерфейс и эксплуатация

- [x] Dashboard, задачи, проекты, сотрудники и прогнозы проверены на 1440×900, 1280×720 и 390×844: HTTP 200, без переполнения и битых изображений.
- [x] Клавиатурный фокус доступен; ошибок и предупреждений в консоли браузера нет.
