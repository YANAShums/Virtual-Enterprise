# План редизайна Virtual Enterprise

## Исходное состояние

Восемь страниц: login, dashboard, employees/list, employees/form, projects/list, projects/form, kanban/board, workload/index. Общий fragment layout, один CSS, два JS. Bootstrap 5.3.3 и Bootstrap Icons 1.11.3 уже подключены. Spring Boot 3.5.3, Java 21. Отдельных страниц деталей и административных справочников нет.

## Порядок

1. Светлый shell с sidebar 248 px, topbar, мобильным offcanvas, CSS tokens.
2. Общие компоненты, вход и обзор.
3. Сотрудники, проекты, формы и представления деталей на существующих данных.
4. Kanban, доступное изменение статуса, форма назначения с расчётом загрузки.
5. Загрузка: легенда, дневная детализация, состояния ошибок.
6. Административные справочники с существующими правами и данными.
7. Документация, локальный UI kit, проверка шаблонов и пользовательских сценариев.

## Сохраняемые контракты

POST /login, /logout, /employees, /projects; GET-фильтры существующих страниц. POST /api/v1/tasks/workload-preview, POST /api/v1/tasks, PATCH /api/v1/tasks/{id}/status. CSRF, version, calculationRequestId и подтверждение CRITICAL обязательны. Расчёт нагрузки и схема БД не меняются.

Данные отсутствующих модулей (компетенции, история нагрузки, уведомления, редактирование справочников) не имитируются. Ограничения отражаются в документации и интерфейсе; нерабочие кнопки не добавляются.
