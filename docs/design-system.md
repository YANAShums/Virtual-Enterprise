# Дизайн-система FlowStaffAI

Редакция 29 октября 2026 года. Визуальное направление утверждено пользователем по приложенному примеру и инструкции: Black × Lilac × Lime. Предыдущий зелёный дизайн и горный баннер заменены.

## Файлы и стек

React, TypeScript, Vite, React Router, TanStack Query, Radix Dialog, Phosphor Icons. Backend, бизнес-правила, Spring Session, CSRF и серверные контракты сохранены.

- `frontend/src/tokens.css` — цвета, типографика, шкала отступов, радиусы, размеры, тени, motion и слои.
- `frontend/src/styles.css` — базовая компоновка и совместимость существующих серверных контрактов; цвета связаны с токенами.
- `frontend/src/product-theme.css` — визуальная система и адаптивные правила.
- `frontend/src/ui.tsx` — Button, Panel, Empty, StatusBadge.
- `frontend/src/overview.tsx` — обзор организации и график плановой загрузки.
- `frontend/src/people.tsx` — список сотрудников с панелью выбранной записи.
- `frontend/src/design-system.tsx` — интерактивный UI-кит, только Vite dev, `/dev/design-system`.

## Шрифты

Основной стек: `Suisse Intl, Onest, system-ui, sans-serif`. Предоставленный пользователем Suisse Regular хранится локально в `frontend/src/assets/suisse/SuisseIntl-Regular.ttf`. В файле есть латиница, но нет кириллицы. По подтверждённому выбору пользователя русский текст отображается локальным Onest; латиница использует предоставленный Suisse. Состав гарнитур указан явно.

Файл Suisse имеет настоящий вес 400. Веса 500–700 синтезируются браузером; при предоставлении соответствующих лицензированных файлов нужно добавить отдельные `@font-face`. Не объявлять статический файл вариативным и не загружать нелицензированные начертания.

Данные: локальный JetBrains Mono 500 и 600 из [официального репозитория JetBrains](https://github.com/JetBrains/JetBrainsMono). OFL-лицензия сохранена рядом. Он используется для KPI, процентов, дат, Task ID, версии модели и вероятностей. Обычный текст не набирается моноширинным шрифтом.

## Компоновка и компоненты

Шкала отступов: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64 px. Sidebar 216 px, на компактном desktop 208 px. Topbar 64 px; горизонтальный отступ контента 24–32 px. Карточки 12 px, поля и кнопки 8 px, диалоги 14 px. Основная иерархия строится на поверхности, границе, отступе и типографике; тяжёлые тени и декоративный blur не используются.

Навигация сгруппирована: Работа, Команда, Кадровая аналитика, Система. Активный пункт выделяется тёмной поверхностью и узким lime-индикатором. Пункты и действия видимы согласно серверным правам. Поиск честно обозначен как поиск задач. Период верхней панели — переход к загрузке ближайших семи дней, а не фиктивный глобальный фильтр.

Главная: четыре реальных показателя, плановая загрузка, сохранённые кадровые прогнозы, проекты, просроченные задачи и сроки. Нет вымышленных изменений к прошлому месяцу, AI-прогноза загрузки или искусственной ленты активности.

Проекты: список с поиском и переключением в карточки. Задачи: рабочая таблица, статусы, комментарии и чек-лист. Kanban: нейтральные колонки и карточки, семантическая метаинформация; drag target выделяется lime, клавиатурная альтернатива — смена статуса в select. Сотрудники: список и панель выбранной записи, на узком экране последовательная компоновка. Полный профиль сохраняет обзор, задачи, график, отсутствия, навыки, текучесть и кадровую историю.

Загрузка: рабочие состояния и пороги определяет backend. Примеры из дизайн-брифа не меняют реальные пороги. Прогнозы используют lilac для модели и семантические цвета для LOW/MEDIUM/HIGH/CRITICAL. Вся вероятность и версии — шрифт данных.

## Доступность

Одного цвета недостаточно: у состояния всегда есть подпись. Видимый клавиатурный фокус сочетает lime с контрастным тёмным контуром. Все поля подписаны. Radix-диалоги имеют заголовок, описание, Escape и возврат фокуса. Вкладки поддерживают стрелки, Home и End. Смена страницы возвращает её к началу без нежелательной прокрутки от фокуса. Reduced-motion отключает анимации.

Проверять 1920×1080, 1440×900, 1280×720, 1024×768, 390×844. Таблицы и доска прокручиваются внутри контейнеров. Документ не должен расширяться горизонтально. Проверять формы с ошибками, поиск, вкладки, диалоги, выгрузки, ограничения ролей и состояния отказа сервисов. `npm run check` проверяет TypeScript; `mvn clean package` собирает React и выполняет Java-тесты.
