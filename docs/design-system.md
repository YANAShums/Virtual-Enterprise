# Дизайн-система Virtual Enterprise

Актуальная редакция: 9 сентября 2026. Интерфейс переработан по официальным экранам Яндекс Трекера. Предыдущая концепция с широким sidebar и плитками заменена компактной навигацией, белой рабочей областью и спокойными таблицами.

## Визуальные источники

- [Доски Трекера](https://yandex.ru/support/tracker/ru/quick-start/setup-for-team/create-board)
- [Карточка задачи](https://yandex.ru/support/tracker/ru/quick-start/setup-for-team/create-issue)
- [Проекты](https://yandex.ru/support/tracker/ru/quick-start/setup-for-team/create-entities)

Оригинальные опубликованные изображения сохранены в `output/playwright/tracker-reference/`. Рабочий кабинет Яндекса требует авторизации; абсолютное совпадение всех его состояний не подтверждено. Названия и значения в приложении поступают из его базы. Фиктивные задачи, комментарии, уведомления и графики не добавлялись.

## Загрузка и статусы

| Код сервиса | Текст | Визуальное обозначение |
|---|---|---|
| SEVERE_UNDERLOAD | Сильно ниже нормы | Светло-зелёный |
| UNDERLOAD | Ниже нормы | Светло-зелёный |
| NORMAL | Норма | Светло-синий |
| WARNING | Повышенная | Светло-жёлтый |
| CRITICAL | Критическая | Светло-красный |
| UNAVAILABLE | Нет данных | Серый |

Процент и статус приходят из сервиса. Цвет всегда дополнен текстом. Перегрузка не окрашивает всю задачу. Статусы задач: запланировано — жёлтый, в работе — синий, на проверке — фиолетовый, выполнено — зелёный, отменено — серый.

## Сетка

- Навигация 64 px; раскрывается до 232 px. Предпочтение сохраняется локально.
- Верхняя панель 48 px: хлебные крошки, поиск задач, меню аккаунта.
- Контент: 32 px по горизонтали; доска: 24 px; телефон: 16 px.
- Ниже 992 px навигация открывается как Bootstrap Offcanvas.
- Карточка проекта/задачи: основное содержимое и правая панель параметров 320 px.
- На телефоне параметры и содержимое располагаются вертикально.
- Таблицы и доска прокручиваются внутри своей области.

## Реальные действия

- Глобальный поиск отправляет GET /tasks. Фильтры: запрос, проект, статус, «назначены мне», просроченность.
- Заголовок карточки открывает /tasks/{id}; параметры загружаются из базы.
- Смена статуса использует прежний PATCH API и version. Недопустимые переходы заблокированы. Для возврата или отмены запрашивается комментарий.
- Критическая перегрузка требует явного подтверждения. Изменение проекта, часов или дат сбрасывает выбор кандидата.
- Формы сотрудника и проекта используют прежние Thymeleaf bindings. Участников проекта можно искать и выбирать чекбоксами.
- Справочники администратора показывают существующие записи. Создание сотрудника доступно ADMIN.

## Архитектура

Сохранён стек Spring Boot, Thymeleaf, Bootstrap и JavaScript. API расчёта нагрузки и изменения задач не менялся. Для списка и подробностей задач добавлены контроллер представления и сервис чтения.

CSS: `app.css` → tokens, base, layout, components, pages/{dashboard,employees,kanban,workload,admin}.
Фрагменты: layout (head, navbar, scripts), ui (состояния), tasks (общая таблица).

UI Kit: /dev/ui-kit, только профиль dev и роль ADMIN. Примеры компонентов обозначены как примеры, они не подмешиваются в пользовательские списки.

## Доступность

Есть skip-link, labels, видимый focus, текстовые статусы, названия иконок. Навигация вкладок сотрудника поддерживает стрелки, Home и End. Смена статуса доступна через select без drag-and-drop. Формы проверяют даты, обязательные поля и серверные ошибки. Новые уведомления используют role status/alert.

## Границы

Расписание, сотрудники и расчёт загрузки — адаптация визуального языка Трекера к этому приложению. Функции Яндекса без backend-аналога (спринты, вложения, обсуждения, избранное, уведомления) не изображены работающими кнопками. Авторизация использует аккаунты Virtual Enterprise.
