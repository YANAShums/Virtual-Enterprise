# Навыки задачи и команда проекта

03.11.2026

- В новой задаче раздел «Требуемые навыки» всегда виден. Если справочник пуст, показано объяснение, где администратор может его заполнить. Примерные навыки автоматически не создаются.
- При наличии справочника можно выбрать несколько навыков предприятия проекта. Изменение требований сбрасывает расчёт и выбранного исполнителя; IDs отправляются в workload-preview и сохранение задачи существующим контрактом.
- Процент совпадения навыков показывается рядом с загрузкой кандидата. Неполное совпадение влияет на рейтинг, но не блокирует назначение.
- Из формы задачи доступна ссылка на редактирование команды проекта в новой вкладке, если пользователь вправе управлять проектом. После сохранения команды следует пересчитать исполнителей.
- Список проектов формы ограничен правом создания задач; навыки передаются для предприятий доступных проектов.

## Как добавить участника

Проекты → нужный проект → Редактировать → Команда проекта → отметить сотрудника → сохранить. Руководитель добавляется автоматически. Действие доступно администратору, руководителю предприятия и руководителю данного проекта. Руководитель подразделения команду проекта не редактирует; при создании задачи ему также доступны сотрудники его подразделения согласно области доступа.

## Как заполнить навыки

Администратор: Сотрудники → карточка сотрудника → Навыки → Добавить. Указать название и уровень. Новый навык попадает в справочник предприятия и затем доступен в новой задаче. Заполнение требований задачи необязательно.

## Проверка

React/TypeScript и Docker-сборка прошли. Chromium проверил пустое состояние, переход к составу команды, форму при 1440×900, 1280×720, 390×844 без переполнения, выбор навыков, сброс расчёта и передачу requiredSkillIds. Для проверки непустого списка подменялся только ответ в тестовом браузере; записи сотрудников и навыков в базе не менялись. Локальные результаты: output/task-skills.
