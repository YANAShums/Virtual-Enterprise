# Проверка дизайна по образцам Яндекс Трекера

Дата: 9 сентября 2026. Реализация: Spring Boot / Thymeleaf / Bootstrap / JavaScript. Адрес: http://localhost:8080.

## Объём и источники

Обновлены вход, главная, сотрудники, проекты, подробности сотрудника и проекта, доска, создание задачи, загруженность, дневная панель, административные справочники. Добавлены рабочие список и подробности задач. UI Kit использует те же стили.

Источники:

- [Официальные экраны досок](https://yandex.ru/support/tracker/ru/quick-start/setup-for-team/create-board).
- [Официальный экран задачи](https://yandex.ru/support/tracker/ru/quick-start/setup-for-team/create-issue).
- [Официальный экран проекта](https://yandex.ru/support/tracker/ru/quick-start/setup-for-team/create-entities).

Локальные источники: `output/playwright/tracker-reference/first-board.png` (1480×923), `scrum-board.png` (1329×882), `issue.png` (1461×1010), `project.png` (1406×910). Это опубликованные снимки продукта; содержимое карточек источника не перенесено в приложение.

Рабочий кабинет Яндекса требует авторизации. Пиксельное совпадение всех его экранов и состояний не подтверждено. Шрифт Arial заменяет фирменную гарнитуру; значки — Bootstrap Icons. Полный клон функциональности Яндекса не заявляется.

## Сопоставление визуальных областей

Исходные и реализованные снимки просматривались рядом. Для доски дополнительно сохранён `board-comparison.png` при том же размере 1480×923, что первый источник. В исходном снимке доски нет общей боковой навигации; её геометрия сверялась по снимку задачи.

| Область | Проверка реализации |
|---|---|
| Геометрия | Навигация 64 px, header 48 px, белая рабочая область; тонкие разделители |
| Типографика | Уменьшена декоративность, заголовки 28/18 px, карточки задач 16 px |
| Цвет | Серые колонки, белые карточки, синие действия и активные вкладки, мягкие статусы |
| Компоненты | Контуры карточек и полей, отступы, радиусы колонок и правой панели сверены со снимками |
| Содержимое | Названия, числа, исполнители, часы и даты из текущей базы и сервиса нагрузки |
| Детали задачи | Основной текст слева, параметры справа; нет фиктивных комментариев или вложений |
| Детали проекта | Описание, задачи и команда слева; статус, сроки, руководитель и часы справа |
| Дополнительные экраны | Сотрудники и загруженность адаптированы к визуальному языку источника |

Осознанные различия: состав статусов и фильтров соответствует backend Virtual Enterprise; на карточке сохранены часы и загрузка, которых нет на приведённом снимке Трекера. Собственные названия продукта и проектов сохранены. Статистический показатель pixel-diff не вычислялся: содержимое и набор функций различаются.

## Функциональная проверка

- 14 серверных тестов: 11 проверок MVC/Thymeleaf, 2 проверки фильтрации задач, 1 проверка расчёта нагрузки.
- 18 серверных экранов: HTTP 200, ошибок JavaScript нет.
- 17 браузерных проверок: поиск доски, пустой результат, восстановление поиска, отмена изменения статуса, блокировка создания, реальные кандидаты, выбор и сброс, критическое подтверждение, геометрия footer, вкладки и клавиатура, серверный поиск, дневная панель, мобильное меню и ссылка создания.
- Проверены права EMPLOYEE: создание задачи скрыто, чужие статусы заблокированы, фильтр «назначены мне» возвращает обе задачи сотрудника в существующих проектах, /admin возвращает 403.
- Показатели и списки не подменялись через перехват API. При проверке не создавались сотрудники, проекты или задачи.
- Синтаксис всех трёх рабочих JavaScript-файлов проверен Node.

Изменение статуса проверено до отправки при отмене диалога; сценарии успешной записи задачи и перевода статуса в этой визуальной проверке не выполнялись, чтобы не менять существующие записи. Серверные контракты и бизнес-правила сохранены.

## Адаптивность

Основные снимки: 1440×960. Телефон: 390×844, 12 экранов; дополнительные проверки: 768×900 и 320×900.

При проверке исправлены:

1. Дублирующая кнопка меню на desktop.
2. Утечка геометрии скрытых подписей за область таблицы и доски на mobile.
3. Перенос заголовка и статуса проекта на экране 320 px.
4. Временное отображение выбранного статуса до подтверждения диалога.
5. Повторное открытие формы после создания через ссылку create=1.

Footer формы располагается отдельно от прокручиваемого тела. Таблицы и доска имеют собственную горизонтальную прокрутку. После финальной сборки проверки при 320, 390, 768 и 1440 px не обнаружили глобального горизонтального переполнения. Раскрытие меню, сохранение его состояния и выбор проекта также проверены.
