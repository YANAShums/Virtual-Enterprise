# Правила интерфейса FlowStaff AI

По запросу пользователя от 18 октября 2026 интерфейс переведён на React + TypeScript + Vite. Эта редакция заменяет прежние правила Thymeleaf AppShell и бирюзовой темы.

- Дизайн: docs/design-system.md. Код интерфейса — frontend/src; токены — frontend/src/styles.css.
- Графитовые поверхности, коралловый акцент, текстовая навигация, локальный Onest, немного Phosphor Icons. Не возвращать Bootstrap, Lucide и декоративные KPI.
- Данные и права определяет backend. Сохранять Spring Session, CSRF, версии записей, ограничения статусов, пороги загрузки и риска.
- enterprise-app/src/main/resources/ui-contracts — внутренний серверный контракт чтения и форм. React разбирает его в компоненты. Нельзя исполнять скрипты, обработчики или вставлять ответ через dangerouslySetInnerHTML. Контроллеры и бизнес-логика остаются прежними.
- Новые самостоятельные экраны писать компонентами React; для новых данных предпочтительны явные JSON DTO. Адаптер не расширять новой бизнес-логикой.
- Диалоги — Radix, с заголовком, описанием, возвратом фокуса и Escape. Все действия доступны с клавиатуры; reduced-motion обязателен.
- Проверять страницы и действия в браузере при 1440×900, 1280×720, 390×844. Таблицы и доска прокручиваются внутри контейнеров; страница не расширяется по горизонтали.
- mvn clean package собирает React и запускает Java-тесты. npm run check в frontend проверяет TypeScript. Браузерный сценарий — tools/browser-react-acceptance.js.
- Коммиты: следующий порядковый номер и краткая безличная формулировка на русском.
