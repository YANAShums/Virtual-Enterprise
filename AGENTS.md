# Правила интерфейса FlowStaff AI

При создании или изменении любого экрана соблюдайте `docs/design-system.md` и существующие токены `enterprise-app/src/main/resources/static/css/tokens.css`.

Источник требований: предоставленный пользователем `FlowStaff_AI_UI_Kit_Design_System.docx`. Эта система заменяет прежнее оформление по Яндекс Трекеру. Новые страницы должны продолжать тот же стиль без дополнительного запроса пользователю.

- Используйте общий Thymeleaf AppShell из `fragments/layout.html`, компоненты `fragments/ui.html` и общие CSS-модули.
- Sidebar тёмно-бирюзовый, TopBar фиксирован; прокручивается основной контент. Фон #F3FAFC, основной акцент #16B8B1.
- Шрифт Onest (локальный), веса 400/500/600. Иконки только Lucide из локального набора. Не добавляйте Bootstrap Icons, emoji или новый основной шрифт.
- Компоненты, радиусы, отступы и состояния берите из дизайн-системы; не возвращайте `theme-accent.css` и не добавляйте отдельные слои переопределений.
- Показывайте реальные данные backend. Не придумывайте динамику KPI, прогнозы, уведомления, навыки или историю сотрудника. Неактивные будущие возможности обозначайте честными пустыми состояниями.
- Визуальная работа не меняет роли, права доступа, API, статусы и пороги нагрузки. Числа и подписи должны сохранять смысл сервиса.
- Проверяйте затронутые страницы и действия в браузере: desktop 1440×900, компактный 1280×720, mobile 390×844. Сохраняйте клавиатурный доступ, focus, aria-label и reduced-motion.
- Коммиты: следующий порядковый номер и краткая безличная формулировка на русском, например «6. Обновлён дизайн (навигация, страницы и компоненты)».
